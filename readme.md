# Currency Converter JS 💱🚀

A simple and responsive **Currency Converter Web App** built using **HTML, CSS, and JavaScript**, with live exchange-rate API and dynamic flags.

This project converts one currency to another in real time using a public API, making it a great beginner-friendly project for learning API calls, DOM manipulation, and frontend development.

---

## 🔧 Features

- 🔹 Real-time currency conversion  
- 🔹 Fetches live exchange rates from a free public API  
- 🔹 Dropdowns with all currency codes  
- 🔹 Flags update automatically based on selected currency  
- 🔹 Fully responsive design  
- 🔹 Clean UI with simple interactions  

---

## 🛠 Tech Stack

- **HTML**
- **CSS**
- **JavaScript (ES6)**
- **Fetch API**
- **Currency API (latest.currency-api.pages.dev)**

## 📄 How to Run

1. Clone the repository  
   ```
   git clone https://github.com/Udayraika18/Currency-Converter-JS.git
   ```
2. Open `index.html` in your browser  
3. Enter amount → choose currencies → click Convert  
4. See real-time results
